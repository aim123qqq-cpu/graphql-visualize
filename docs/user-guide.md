# Руководство пользователя

## 1. Открыть сервис

Откройте сайт:

https://graphql-visual.ru/

Если браузер показывает старую версию интерфейса после обновлений, выполните жесткую перезагрузку страницы:

- Windows: `Ctrl+F5`
- macOS: `Cmd+Shift+R`

## 2. Построить схему

1. Откройте левую панель.
2. Вставьте GraphQL SDL или introspection JSON в поле схемы.
3. Нажмите `Построить граф`.
4. При необходимости нажмите `Оптимизировать`.

## 3. Навигация по графу

- Колесо мыши: приблизить или отдалить схему.
- Перетаскивание пустого места: переместить область просмотра.
- Перетаскивание блока: изменить положение блока.
- Клик по блоку: открыть его детали справа.
- Клик по стрелке: выделить связь.
- Клик вне стрелки: снять выделение стрелки.

## 4. Работа с блоками

После клика по блоку справа отображается карточка типа:

- имя типа;
- список полей;
- тип каждого поля;
- форма добавления нового поля.

Если поле ссылается на другой блок, тип поля в правой панели становится кликабельным. При клике сервис открывает и подсвечивает целевой блок.

## 5. Добавление поля

1. Кликните по нужному блоку.
2. В правой панели введите имя поля.
3. Выберите тип поля из выпадающего списка.
4. Нажмите `Добавить в схему`.

После добавления:

- поле добавляется в SDL;
- граф перестраивается;
- схема сохраняет ручные позиции блоков, если они уже были изменены.

## 6. История

Сервис хранит историю построенных схем в браузере. При клике на запись истории открывается:

- исходный SDL;
- соответствующая визуализация.

История хранится локально в браузере пользователя.

## 7. Темы и панели

- Светлая и темная тема переключаются кнопкой в верхней части интерфейса.
- Левую и правую боковую панель можно скрывать кнопками на самих панелях.
- При скрытых панелях кнопки остаются доступными, а стрелки графа не должны перекрывать элементы управления.
