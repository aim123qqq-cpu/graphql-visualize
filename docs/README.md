# GraphQL Visualizer: документация

GraphQL Visualizer - веб-сервис для визуализации GraphQL SDL и introspection JSON в виде интерактивной схемы. Сервис помогает быстро увидеть типы, поля, связи между блоками и экспортировать результат.

Рабочий сайт: https://graphql-visual.ru/

## Коротко

1. Вставьте GraphQL SDL или introspection JSON в левую панель.
2. Нажмите `Построить граф`.
3. Используйте `Оптимизировать`, если нужно разнести блоки и сделать связи читаемее.
4. Двигайте блоки вручную, кликайте по блокам и стрелкам, изучайте детали справа.
5. Экспортируйте схему в SVG, PNG или draw.io.

## Для кого сервис

- Аналитики и архитекторы API.
- Backend-разработчики.
- Frontend-разработчики, которым нужно понять структуру GraphQL API.
- Команды, которым нужно быстро показать схему GraphQL в презентации, документации или draw.io.
