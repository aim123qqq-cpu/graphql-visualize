# Решение частых проблем

## Не обновилась новая версия сайта

Причина: кэш браузера или GitHub Pages.

Что сделать:

1. Нажмите `Ctrl+F5`.
2. Подождите 1-3 минуты после деплоя.
3. Проверьте, что `index.html` подключает нужный JS-файл с новой версией.

## GitHub Pages показывает 404

Проверьте:

- включен ли GitHub Pages;
- выбран ли правильный branch;
- есть ли `index.html` в корне публикации;
- правильно ли настроен custom domain.

## HTTPS не включается

Проверьте DNS:

- apex-домен должен указывать на GitHub Pages A-записями;
- `www` должен указывать CNAME на `aim123qqq-cpu.github.io`;
- в репозитории должен быть `CNAME` с `graphql-visual.ru`.

После исправления DNS иногда нужно подождать.

## Стрелка залипла и не снимается

Фикс реализован в `edge-clear-patch.js`. Если проблема видна после обновления:

1. Выполните `Ctrl+F5`.
2. Убедитесь, что `index.html` подключает `edge-clear-patch.js`.
3. Кликните по пустому месту или по блоку - выделение стрелки должно сняться.

## Блоки сбрасывают положение после перемещения

Фикс реализован в `field-edge-patch.js`: ручные координаты сохраняются и применяются после перерисовки.

Если сброс повторяется:

- проверьте, что загружена актуальная версия `field-edge-patch.js`;
- выполните жесткую перезагрузку страницы.

## Добавленное поле не попадает в SDL

Поле должно добавляться через форму в правой панели. После добавления SDL обновляется в левом поле и граф перестраивается.

Если поле не добавилось:

- проверьте, выбран ли блок;
- проверьте, заполнено ли имя поля;
- проверьте, выбран ли тип поля;
- проверьте, что имя поля не дублируется в этом типе.

## Introspection URL не загружается

Чаще всего причина - CORS на стороне GraphQL-сервера.

Решения:

- вставить introspection JSON вручную;
- настроить CORS на сервере;
- получить JSON через backend/proxy и вставить в поле схемы.
