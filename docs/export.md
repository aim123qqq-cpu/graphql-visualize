# Экспорт схем

Сервис поддерживает экспорт схемы в несколько форматов.

## SVG

SVG подходит для:

- документации;
- вставки в HTML;
- дальнейшего редактирования в векторных редакторах;
- сохранения четкости при масштабировании.

## PNG

PNG подходит для:

- быстрых скриншотов;
- презентаций;
- отправки в чат;
- вставки в документы.

Экспорт PNG должен учитывать текущую схему, блоки, стрелки и фон. Если картинка выглядит странно, сначала нажмите `Оптимизировать`, затем повторите экспорт.

## draw.io

Формат draw.io нужен, если схему нужно редактировать в diagrams.net/draw.io.

Типичный сценарий:

1. Построить схему.
2. Разнести блоки.
3. Экспортировать в draw.io.
4. Открыть файл в diagrams.net.
5. Доработать схему вручную.

## Рекомендации перед экспортом

- Сначала проверьте масштаб.
- Разнесите блоки вручную, если нужно.
- Выделение стрелки лучше снять перед экспортом, если оно не нужно на финальной картинке.
- Для больших схем допустимо делать очень широкий холст.
