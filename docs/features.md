# Функции платформы

## Построение графа

Сервис строит граф из GraphQL SDL или introspection JSON. Блоки располагаются так, чтобы связи читались визуально, а стрелки меньше пересекались.

## Оптимизация расположения

Кнопка `Оптимизировать` перестраивает граф. Она полезна, если:

- блоки наложились друг на друга;
- стрелки читаются плохо;
- нужно разнести схему шире;

## Ручное перемещение блоков

Блоки можно перемещать мышью. Ручные позиции сохраняются в памяти страницы и применяются обратно после перерисовок.

## Стрелки

Стрелки:

- идут от конкретного поля;
- имеют углы около 90 градусов;
- используют закругленные повороты;
- могут быть красными, синими или черными;
- подсвечиваются при клике.

Если клик по стрелке не попал точно в линию, сервис пытается выбрать ближайшую стрелку в небольшой зоне вокруг нее.

## Правая панель

Правая панель показывает детали выбранного блока:

- имя блока;
- тип блока;
- список полей;
- типы полей;
- форму добавления поля.

Типы полей, которые ссылаются на существующие блоки, кликабельны. Клик открывает и подсвечивает целевой блок.

## История

История хранит ранее построенные схемы в браузере. Это удобно для возврата к прошлым SDL без повторного копирования.

## Темная и светлая тема

Платформа поддерживает две темы:

- светлая;
- темная.

Цветовой акцент - красный.

## Скрытие панелей

Левую и правую панель можно скрывать, чтобы освободить место под схему.
