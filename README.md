# GraphQL Визуализатор

Русскоязычная веб-платформа для визуализации GraphQL-схем. Проект но работает как статическая страница: с форматами SDL или introspection JSON.

## Возможности

- разбор GraphQL SDL;
- разбор introspection JSON;
- загрузка `.graphql`, `.gql`, `.json`;
- попытка загрузить introspection с GraphQL endpoint;
- интерактивный SVG-граф;
- поиск по типам и полям;
- просмотр деталей узлов и связей;
- предупреждения по схеме;
- экспорт в DOT, SVG и PNG.

## Запуск

Откройте файл `index.html` в браузере. Сервер и сборка не требуются.

## Примечание

Загрузка схемы по URL выполняется из браузера. Если GraphQL-сервер не разрешает CORS, вставьте introspection JSON вручную.
