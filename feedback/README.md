## Как это работает

1. Пользователь нажимает кнопку `?` в шапке сайта.
2. На hover показывается подсказка `Поделитесь мнением`.
3. По клику открывается модальное окно на сайте.
4. Форма отправляет `POST /api/feedback`.
5. Backend с GitHub token создает отдельный файл в `feedback/entries/` и добавляет строку в таблицу выше.

Важно: GitHub token нельзя хранить во frontend-коде. Endpoint должен жить на серверной стороне: например Cloudflare Worker, Vercel Function или другой backend.
